## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-17 | Tampering | fabricated or foreign artefact id recorded as proof | high | mitigate | tenant-scoped live read; outcome sent + provider id (or last_event delivered) required; DB CHECK on artefact length |
| T-10-18 | Tampering | proof recorded for an unarmed channel | medium | mitigate | the action refuses unless the channel's armed item is satisfied (same derivation the card renders) |
| T-10-19 | Elevation | any session posting recordProofAction | high | mitigate | requireOperatorId first, authorize second, nothing read before both; pure suite pins it |
| T-10-20 | Information disclosure | addresses or bodies in artefact_detail / sentences | medium | mitigate | artefact_detail holds ids, statuses, domains, timestamps only; the escalation read has no to_address in its select list; outcome text bounded before it enters a sentence |
