<objective>
The tracer: a prospect submits the audit request form on the existing host without an account, the request lands as a tenant-independent `audit_requests` row through the service-role repository, the operator is emailed and texted inside the same request, and the row's existence is proven by a read-only count against the hosted database. Every layer this phase modifies on the intake path (schema + migration, repository, env, intake validation, marketing route group, server action, alert email, operator SMS, proxy matcher) is touched once, thinly, end-to-end, on `app.backdesk.com.au` before any DNS work.

Purpose: prove the architecture (public route group inside the authenticated console, service-role write of a tenant-less table, operator SMS that bypasses the tenant arming gate) on one committed path before the expansion plans widen it. The console list (09-09), the CSV upload, honeypot and throttle (09-03), the landing page and privacy notice (09-05), the console detail and pre-fill (09-06), host-aware routing (09-04) and DNS (09-07) all build on this slice without changing its shape.

Output: migration 0035 applied to the hosted database, the public `/audit` form live on the app host, the two notification senders, the row-count script, five new test suites plus the rls-coverage edit, and `COVERAGE.md`.
</objective>

<assumption_delta_decision>
noun: audit intake source
decision: no-change
rationale: The console intake already models `source` as the closed pair `PROSPECT_SOURCES = ['api_key', 'csv']` on `prospects` (src/db/schema/prospects.ts). The public request does not introduce a third source. An `audit_requests` row carries a nullable `csv_object_path`; the 09-06 pre-fill derives the console `source` from it (`csv` when a stored object exists, otherwise `api_key`, the operator obtaining the key from the prospect per D-15). The optionality of the CSV is therefore represented as a nullable column on the request, not as a new source value, and the existing `PROSPECT_SOURCES` vocabulary stays the only source model.
</assumption_delta_decision>
