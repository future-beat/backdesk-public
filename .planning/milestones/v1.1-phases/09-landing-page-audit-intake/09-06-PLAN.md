## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-9-09 | Information disclosure | request id enumeration via the CSV route | high | mitigate | `requireOperator()` first; 404 for denied, malformed, unknown and file-less alike; no 401/403 in the route |
| T-9-18 | Elevation of privilege | status action / pre-fill action self-authorising | high | mitigate | Auth first before the body is read (WR-01/CR-01), uuid shape checks, repository writes only after the check; tests assert the denied path calls nothing |
