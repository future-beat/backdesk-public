<objective>
Close UAT gaps G-09-1 and G-09-2 from the live phone test (2026-09-10): the optional CSV field refused an empty submission, and the landing page's primary buttons showed unreadable (green-on-green) labels.
</objective>

<context>
- G-09-1: `src/app/(marketing)/audit/actions.ts` treats `formData.get('csv_file')` as an attachment whenever it is a `File` with a non-empty name. Real browsers submit an empty `<input type="file">` as a multipart part with `filename=""` and zero bytes; some runtimes reconstruct that part as a `File` whose `name` is not `''` (e.g. `"blob"` or `"undefined"`). The sniff then fails on the `.csv` suffix and returns the `type` sentence. `tests/audit-request-action.test.ts` only ever omits the field (`if (file) data.set(...)`), so the browser shape was never exercised.
- G-09-2: `src/app/(marketing)/marketing.css` has `.marketing a { color: var(--accent); text-decoration: underline; }` (specificity 0,1,1) which beats `.button { color: var(--accent-fg) }` (0,1,0) in `src/app/globals.css`, so `<a class="button button--lg">` renders green text on the green background.
</context>
