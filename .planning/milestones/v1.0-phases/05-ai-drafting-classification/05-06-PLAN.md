Classify inbound replies (AI-02) with injection-proof least privilege (AI-03): a tick pass scans unlabelled inbound_messages rows, calls claude-haiku-4-5 via messages.parse with the closed zod enum and no tools, and writes label/confidence/hot columns only. Purpose: labels drive triage priority now and Phase 6's hot-lead escalation later; the blast radius of a fully successful prompt injection is one mislabeled row a human still reviews.
Output: classification pass + pinned-privilege repository writes + fake-client and structural-privilege test suites.
</objective>
