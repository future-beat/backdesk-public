<objective>
Close UAT gap G-05-3: on a ~390px phone the inbox row header renders broken — the
timestamp collides with the THREADED pill with zero gap, and the long classification
pill ("reads as interested — not certain") fragments mid-text across two line boxes
with a sliced rounded border.

The debug session (.planning/debug/inbox-badge-layout-phone.md, status: diagnosed)
confirmed a compound AND-gate cause:

1. 05-07 nested `.badge` spans inside `.touch-when` — a plain block, not the flex
   context every prior `.badge` usage sits in — and JSX strips the newline whitespace
   between the bare timestamp text node and the first badge span, so they render with
   zero separation.
2. `.badge` declares no `display` (spans stay `display: inline`) and no `white-space`,
   so a label long enough to wrap fragments across line boxes and its 999px border
   breaks mid-text (default `box-decoration-break: slice`).
3. At ~390px, `.touch-when { flex: 1 1 12rem }` shares the `.touch-list li` first flex
   line with the content-sized `.meta` phone-number block, squeezing the header to
   ~200px against a ~280px pill — guaranteeing the wrap that exposes defects 1 and 2.

Purpose: triage inbox badges (soft opt-out one-tap, needs-human, hot) are the phone
surface AI-03's low-confidence routing lands on — they must be legible on the device
the operator actually uses.
Output: CSS contract fix in globals.css + one modifier class in the inbox markup.
</objective>

  <action>
    Implement the four fixes G-05-3 prescribes (gap.missing), scoped so the
    quote-detail page — which shares `.touch-when` and passed UAT — renders unchanged.

    1. In src/app/globals.css, make `.touch-when` (currently only `flex: 1 1 12rem`,
       ~line 468) a wrapping flex container: add `display: flex`, `flex-wrap: wrap`,
       `align-items: center`, and `gap: 0.25rem 0.5rem`, keeping `flex: 1 1 12rem`.
       This restores the layout contract `.badge` was designed for: the inbox's bare
       timestamp text node becomes an anonymous flex item separated from the pills by
       the gap (fixing the JSX-stripped-whitespace zero-gap collision for ALL children
       regardless of markup whitespace), and `.badge`'s existing `align-self: center`
       reactivates. Do NOT sprinkle `{' '}` separators into the inbox markup — the
       flex gap is the separation mechanism, per the debug session's fix_rationale.

    2. In the `.badge` rule (~line 348), add three declarations: `display: inline-block`,
       `white-space: nowrap`, `max-width: 100%`. Inline-block means the pill can never
       fragment across line boxes in any future non-flex parent (the sliced-border
       artifact); nowrap means a pill that does not fit its flex line wraps to the next
       line as one whole unit. Keep every existing declaration. The verify counts
       exactly these three declaration lines inside the `.badge` block, so do not
       restate the property:value strings in comment prose within that block.

    3. Add a `.touch-when--stack` modifier in the quote-detail CSS section next to
       `.touch-when`: mobile-first `flex-basis: 100%` so the inbox header owns its full
       row on phones instead of sharing the li's first flex line with `.meta` (the
       ~200px squeeze against a ~280px pill), and restore `flex-basis: 12rem` inside
       the existing `@media (min-width: 32rem)` breakpoint — mirroring how `.touch-meta`
       already handles the same phone/desktop split.

    4. Narrow-viewport fallback for the longest label: under `@media (max-width: 22.5rem)`
       set `.touch-when--stack .badge` to `white-space: normal`. Derivation of 22.5rem
       (360px): the longest pill, "reads as none of the above — a guess" uppercased with
       letter-spacing, measures ~320px rendered (debug session blind_spots), plus main's
       2 x 1.25rem side padding = 360px. Below that width the label wraps INSIDE one
       intact rounded pill (inline-block cannot fragment) instead of overflowing the
       border. Scoped to the stack modifier so short badges elsewhere never change.

    5. In src/app/(console)/inbox/page.tsx line 232, change the row-header div's
       className from "touch-when" to "touch-when touch-when--stack". This is the ONLY
       markup change. Do not touch src/app/(console)/clients/[id]/quotes/[quoteId]/page.tsx:
       its two `.touch-when` spans keep the base class only — under the new flex layout
       their explicit `{' '}` whitespace node is dropped and the 0.5rem column gap takes
       its place, which the debug session judged visually equivalent (eyeballed at the
       UAT resume, not here).
