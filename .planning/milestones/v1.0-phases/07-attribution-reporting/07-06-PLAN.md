<objective>
Close the three Phase 7 UAT gaps with pure CSS/JSX fixes, a pinned source-assertion suite, engine-agnostic print proofs, and corrected contracts — no schema, no migration, no remote suite.

**What the UAT found (07-UAT.md, diagnosed 2026-09-03):**
- **G-07-1** — the iPhone PDF has an entirely blank fourth page. `.report-footer` is a `<p>` whose UA `margin-block-end: 1em` (13.84px) was never reset; in print it collapses out to the root as trailing zero-ink height, and WebKit pages for it (`.planning/debug/report-print-trailing-blank-page.md`, T4/T9/T10). `.audit-footer` carries the same latent defect.
- **G-07-2** — the same PDF shows no header on pages 2–3, row #4208 split across the fold (`Joondalup` orphaned) and `#4201Switchboard upgrade` with no separator. Three causes: `display: table-header-group` is the UA default and repeats nothing; `break-inside: avoid` sat on `tr`, a box no engine keeps whole; and the description span's only block rule is the descendant selector `.report-figure .report-figure-note`, inert inside a `<td>`, so JSX-stripped whitespace glued id to description and the merged inline run made rows 3–4 line boxes tall (`.planning/debug/report-table-pagination.md`). The two diagnoses disagreed on the engine; the planner settled it from the PDF itself.
- **G-07-3** — at 390px the console page widens: `.nav` and `.nav nav` have never had `flex-wrap`, so the brand plus seven links (~497px min-content) overflow a ~350px content box by ~108px onto `Email`/`Sign out` (`.planning/debug/console-nav-overflow-390.md`). `button.linkish { min-height: 0 }` also puts `Sign out` under the 44px nav tap target. 07-UI-SPEC:323 signed E8 off on an "existing flex-wrap nav" that never existed.

Seven columns at the screen sizes cannot be one line in 496px — that is the whole four-page print.

Both G-07-2 pagination symptoms are WebKit behaviour. `break-inside: avoid` on thead does **not** make WebKit repeat the header (WKWebView print, fix applied): accepted engine debt.
- Budget matrix in Chrome with the real `globals.css` + `report.css`: at **661px** (the iPhone column once `zoom: 0.75` restores 96px/in) the seven columns are one line box per row **only** at `font-size: 0.7rem`, `padding: 0.4rem 0.3rem`, `.cell-truncate { max-width: 10rem }` — for `12 (14 Aug–31 Aug)` and an eleven-letter first name; `0.75rem` wraps every row at 661px.
