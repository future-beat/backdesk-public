## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (any POSTer) → server actions | every exported 'use server' function is a globally-POSTable endpoint |
| operator JWT → tenant data | membership decided by Postgres RLS, not by UI state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-18 | Elevation | forged action POST kills/resumes another tenant's cadence | high | mitigate | WR-01 authorize-first with RLS-scoped membership read before formData; zod uuid validation; generic failure copy |
| T-3-19 | Elevation | resume restarts messaging without entitlement | high | mitigate | Same gate; resume additionally routes through the guarded resumeWherePaused + D-07 applier — no direct status write |
| T-3-20 | Repudiation (compliance) | un-suppressing a complained contact | high | mitigate | No delete/update path in controls or repository; grants layer (03-01) denies it to authenticated; see prohibitions |
