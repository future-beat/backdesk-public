<objective>
Close G-3-5 (minor, UAT test 5): stop conflating "the job was deleted in ServiceM8"
with "the quote row vanished from our local mirror".

Today `dispatch.ts` `dispatchOne` (~line 293) writes `stop_reason='removed'` when the
JIT re-read finds NO quote row at all — the same reason the outbox `removed` event and
the `sm8_active=false` read produce for an OBSERVED upstream deletion. User decision at
UAT: these are different facts with different evidence, and Phase 7 attributes revenue
on this column, so they must be different words. Introduce `mirror_missing`, written
only by the missing-row dispatch path; widen the DB CHECK first (migration, 0018/0020
conventions); Phase 7 decides its attribution bucket later — the point is
distinguishability now.

`transitions.ts` needs NO change: the state machine maps outbox EVENTS to outcomes, and
mirror_missing has no event — it is a dispatch-time discovery, like the other
non-matrix stop reasons (`contact_suppressed`, `no_contact`, `operator_closed`).

Purpose: CAD-04's dispatch revalidation records the truth it actually observed, keeping
Phase 7's evidence chain honest.
Output: migration 0022, widened vocabulary, one-word dispatch change with a rewritten
WHY comment, console label, updated + extended dispatch tests.
</objective>
