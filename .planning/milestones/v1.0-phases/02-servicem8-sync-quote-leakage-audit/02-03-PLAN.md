## Phase Goal

**As a** the operator, **I want to** have quote changes flow in automatically every five minutes without me touching anything, **so that** open quotes appear within one polling interval and webhooks can only ever make that faster, never different.

<objective>
Expose the 02-02 engine to the world: the internal tick route (timing-safe bearer auth, syd1, 300s), the proxy matcher fix that keeps the console gate from swallowing API routes, the pg_cron 5-minute schedule (D-13) applied via an idempotent script (secret/URL in env — avoids the unverified Vault-in-migration path, research A7), the weekly cron-details cleanup, and the SYNC-03 webhook hints-to-poll adapter (challenge + re-fetch, activation deferred until OAuth credentials are confirmed for App ID 000000).

Purpose: the tick is the phase's heartbeat; Pitfall 7 (proxy swallowing the route while cron reports green) is the silent failure this plan is built to make impossible.
Output: automatic 5-minute sync in production; webhook route ready to activate.

Requirements: SYNC-01 (the tick, D-13), SYNC-03 (webhooks as hints). RESEARCH Pattern 2, Pitfalls 7, 10.
</objective>
