## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator browser → server actions | Every exported action is a POSTable endpoint |
| Operator-typed wording → members of the public | What is attested here is sent verbatim to callers |
| Operator-typed number → the never-text gate | A mistyped own line weakens the fail-safe |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-11 | Elevation of privilege | an action called by a non-operator or for a tenant the operator does not hold | high | mitigate | Operator then tenant authorization before any `formData` read, pinned with a FormData whose getters throw; all writes through `forTenant(tenantId)`; no authenticated write grant exists on either table |
| T-12-08 | Tampering | a wording that carries a link, drops STOP or the identity, or changes after attestation | high | mitigate | `validateTextBackTemplate` at save and again at attest; write-once attestation with a required note and the operator's id; literal bytes stored, no merge token |
| T-12-23 | Tampering | removing the client's own line while armed, so a carrier that substitutes the diverting line makes Backdesk text the client | medium | mitigate | `removeNeverTextNumber` refuses the last own-line removal while `isTextBackArmed`; the gate also compares the escalation phone, the divert number and ForwardedFrom independently |
| T-12-24 | Tampering | malformed number input stored in a second spelling that the gate never matches | medium | mitigate | One normaliser (`classifyCaller`), E.164 stored, unique on (tenant, number), column CHECK; three spellings of one mobile pinned to one value |
| T-12-07 | Information disclosure | an entered number or a database error reaching a log | medium | mitigate | Fixed-string logs; caught values discarded; tests/console-error-leak.test.ts scans the new files automatically |
| T-12-SC | Tampering | package installs | low | accept | No package is installed in this plan |
</threat_model>
