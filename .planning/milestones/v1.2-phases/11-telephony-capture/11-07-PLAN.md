  <instructions>
    1. Open the chosen client's page on https://app.backdesk.com.au, "Divert number" section: check the spoken name (say it aloud), tap "Find a Perth number" (or the WA fallback), read the candidate sentence — number, locality, about A$3/month, cannot be released — and tap "Buy this number".     2. Note the PN sid.
    3. (Optional, runbook section 6) create the TwiML Bin fallback with the generic greeting and set it on the number's "Primary handler fails".
    4. From your own handset, dial the number directly. Listen: is the greeting intelligible, is the name pronounced acceptably, does it say "automated" and "isn't recorded", does it hang up by itself? Note the perceived length.
    5. Run `npm run missed-calls:recent -- --tenant <uuid> --limit 5`. Expect one row: `call_status completed`, `completed_via callback`, `caller_kind mobile`, `caller_present true`, a `duration_seconds` value. Copy the row id.
    6. On the client page, "Verification call recorded" row → "Missed call id": paste the id, write what you heard as the note, submit. Expect "Recorded. The divert for this client is verified." and the row to read "verified on … · <id>".
    7. Run `npm run verify:missed-call-reconcile`. Expect `calls listed (inbound, 48h): 1` (S7) and `recovered=0 recordings=0`.
    8. Dropped-callback drill (runbook section 9): in the Console change ONE character of the Status Callback token, save; dial the number again from your handset; run `missed-calls:recent` — the new row shows `completed_via -` and `call_status ringing` or `-`; run `npm run verify:missed-call-reconcile` → `recovered=1`; run `missed-calls:recent` again — the SAME row id now shows `completed_via reconcile`, `call_status completed`, and the row count is unchanged (no duplicate). Restore the Status Callback URL exactly; dial once more; confirm the newest row shows `completed_via callback`.
    9. Reply with: the PN sid, the E.164 number, the verification row id and its duration_seconds, the S5 notes (intelligibility, pronunciation, perceived length), the S7 `calls listed` count, the drill row id with its two `completed_via` readings, whether the fallback bin was created, and the lines the reader printed (they contain no caller number). Never paste a handset number or a token.
